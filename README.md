# Virtual Optics Lab: Monte Carlo study (JIIT Physics Lab 1)

- `sim.py`: Python re-implementation of the simulator's validation measurements (double slit, single slit, grating, biprism, Newton's rings).
- `mc.py`: Monte Carlo virtual experiments (Newton's rings, biprism, grating) and analytic error propagation.
- `figs.py`: generates every figure and prints the numbers quoted in the report (NumPy seed 2026).

Run: `python figs.py` (requires numpy, matplotlib, pillow).
The interactive simulator is hosted [here](https://vansul.github.io/virtualopticslab).
